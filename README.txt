TIMBREDEX / STAMPDEX MVP

Open index.html in a browser (or serve this folder with a small local HTTP server; fetch() may be blocked by some browsers when opened directly from file://).

The five JPEGs in stamps/ are simple generated placeholder graphics for the Tintin-themed prototype catalogue. Replace them with your real photographed stamp images using the same filenames (stamp-001.jpeg through stamp-005.jpeg) for real testing. Keep stamps.json beside index.html and preserve the image paths.

This is a visual matching prototype, not a professional authentication or valuation service. The average-hash confidence score is intended for experimentation only.
